---

## 🧐 ¿Qué se hace en este repositorio?

Repositorio de distribución estática que almacena los archivos APK compilados y los metadatos JSON de versión (`updatestable.json`, `updatebeta.json`). Es consultado por el actualizador automático integrado en las aplicaciones.
